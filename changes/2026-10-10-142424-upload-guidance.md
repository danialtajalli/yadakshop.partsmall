## Guidance

Open the Partsmall project in VS Code, reload the window to refresh SFTP
settings, then use the command palette's `SFTP: Upload Project` to upload all
non-excluded source files. For a narrow change, use Upload Active File or
Upload Folder. Confirm the production connection and inspect the SFTP output
for transfer errors. Use ordinary upload, not Force Upload, which may bypass
intended protections.

Uploading source does not change code inside the running Docker images.
A controlled release is still needed. The current source includes new Redis
services and queue settings, so a blanket Compose restart/recreation is not a
safe queue migration. Verify backups, environment/volume readiness, old-queue
drain and worker handoff before publication; see `docker/ops/REMEDIATION.md`.
Excluded environment templates/configuration must be handled separately during
that reviewed release. Preserve live secrets and existing persistent data.
